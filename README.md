## I Build Jamstack & Headless Websites that Loads Instantly

I'm Shihab, a freelance web developer. I build high performing websites in two main ways-

1. **Jamstack** — A modern web development architecture. I heavily use _Astro, Hugo, Jekyll, Gatsby, & Next.js._
2. **Headless CMS** — It's extended version of the Jamstack. In this architecture, you still use a **back-end dashboard** such as **WordPress, Sanity, Strapi** and the front-end is powered by a Jamstack framework.

### Why Use These Technologies?

It is almost impossible to make a slow websites using these technologies. These are fast by born and mostly **opinionated**.

_This approach gives you additional benefits in **SEO, User Experience**, and it reduces your hosting cost._
